# 10. 검증 필요 항목

이 문서의 항목은 포트폴리오 공개 전 반드시 확인해야 한다.

## 학력 / 일정
- [ ] 졸업 예정 시점 정확히 확인 (`2026-08` 표기 자료 존재)
- [ ] GPA 표기 방식 확정 (`3.91/4.5`, `전공 3.96/4.5` 중 병기 여부)

## 수상 / 대회
- [ ] 해커톤 정확한 명칭
- [ ] 해커톤 수상명 확정 (`3등상` / `우수상` 혼재)
- [ ] 2024 SCON 수상명 공식 표기 (`금상(2등)`으로 보이지만 최종 확인)
- [ ] 2025 SCPC 공식 표기 방식 확정
- [ ] 정보올림피아드 수상명 공식 표기
- [ ] SCCC 내부 대회 / 연합대회 수상 표기 여부 확정

## 문제 해결 프로필
- [ ] Baekjoon 프로필 링크
- [ ] Codeforces 프로필 링크
- [ ] 현재 티어와 최고 티어 중 무엇을 표기할지 확정

## 프로젝트
- [ ] xv6 관련 저장소/코드 공개 여부
- [ ] uftrace 관련 기여 링크
- [ ] WOL Docker 저장소/설계 문서/구현 범위 정리
- [ ] Checkhouse 정확한 역할(백엔드 단독인지, 프론트+백엔드인지) 확정
- [ ] Checkhouse 기술 스택 확정
- [ ] Manbo 저장소/스크린샷/맡은 기능 정리
- [ ] Family Community 공개 가능 여부
- [ ] boothmap 공개 가능 여부
- [ ] 학생회 타임테이블 자동화 프로그램 자료 존재 여부
- [ ] 각 프로젝트별 사용 기술, 기간, 팀/개인 여부 최종 확정

## 자격 / 어학
- [ ] OPIc 시험일과 성적표 캡처
- [ ] TOEIC Speaking 시험일과 성적표 캡처
- [ ] TOPCIT / 정보처리기능사 증빙

## 군 복무
- [ ] 포트폴리오에서 군 세부 보직을 쓸지 확정
- [ ] 쓴다면 공식 표기 확인 (`소총수`, `분대장`, 기타 혼재)

## 연락 / 외부 링크
- [ ] GitHub 메인 링크
- [ ] 이력서 PDF
- [ ] 이메일 주소
- [ ] 블로그 링크(있다면)

## 사이트 구성
- [ ] 대표 프로젝트 카드 개수 확정
- [ ] 서비스 프로젝트를 몇 개까지 포함할지 확정
- [ ] 한영 병기 여부 확정
- [ ] 사진/프로필 이미지 사용 여부
