# 13. 소스 인덱스

Codex가 참고해야 하는 원본 파일 목록이다.

## 우선 참고 원본
- `info/Projects.md`
  - 프로젝트 후보, 기술 스택, 대략적인 기간, 팀/개인 여부, 메모 수준 서사
- `info/자소서 모음.md`
  - 지원서에 썼던 문장들, 프로젝트 서사, 수상/활동/학점/어학 정보, 직무별 포지셔닝 흔적

## 읽는 방식
1. 원본에서 **사실**을 찾는다.
2. 정리 문서(`docs`)에서 **해석**과 **우선순위**를 본다.
3. 둘이 충돌하면 원본을 맹신하지도, 정리 문서를 자동 확정하지도 말고 `검증 필요`로 남긴다.

## 대표적으로 충돌/주의가 필요한 항목
- 해커톤 수상명
- 군 보직 세부 표현
- Checkhouse 정확한 역할
- 프로젝트별 정확한 기간
- Codeforces 표기
