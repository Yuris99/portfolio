# 09. 사이트용 초안 문구

이 문서는 포트폴리오 사이트에 바로 넣거나 다듬어 쓸 수 있는 초안이다.

---

## Hero 한 줄
- 시스템 소프트웨어와 로우레벨 개발을 지향하는 C/C++ 개발자
- 운영체제와 메모리 구조에 관심이 많은 시스템 소프트웨어 지향 개발자
- 문제 해결력과 로우레벨 관심을 바탕으로 성장 중인 C/C++ 개발자

## Hero 본문 초안 1
알고리즘을 통해 문제를 구조적으로 바라보는 습관을 길렀고,  
운영체제 수업과 xv6 과제를 통해 시스템 내부 동작을 직접 다뤄보며 로우레벨 개발에 흥미를 갖게 되었습니다.

## Hero 본문 초안 2
저는 서비스의 겉모습보다 시스템이 내부에서 어떻게 동작하는지에 더 끌립니다.  
C/C++ 기반 문제 해결 경험과 운영체제 학습을 바탕으로 시스템 소프트웨어 직무를 준비하고 있습니다.

---

## About 초안
알고리즘은 제게 단순한 코딩 테스트 준비가 아니라, 복잡한 문제를 빠르게 구조화하고 제한된 조건 안에서 최적의 해법을 찾는 훈련이었습니다. 이 경험은 운영체제 과제와 시스템 코드 분석을 접했을 때도 그대로 이어졌습니다.

운영체제와 시스템 프로그래밍 수업 이후에는 프로세스, 스케줄링, 메모리 관리처럼 시스템 내부 동작에 관심을 갖게 되었고, xv6 수정 과제와 오픈소스 컨트리뷰션 경험을 통해 로우레벨 소프트웨어에 더 가까이 다가가고 있습니다.

---

## Highlights 초안
### Problem Solving
교내 알고리즘 대회 수상과 삼성 SCPC 본선 진출 경험을 통해, 빠르게 구조를 파악하고 효율적인 해법을 찾는 역량을 길렀습니다.

### OS / Low-level
운영체제 과제에서 xv6의 시스템 콜, 스케줄러, 메모리 관련 코드를 직접 수정하며 시스템 내부 흐름을 배웠습니다.

### Open Source
uftrace 트랙 참여를 통해 실행 흐름 추적 도구와 오픈소스 협업 방식을 접하며 Linux 기반 로우레벨 생태계에 대한 관심을 키웠습니다.

---

## Project 카드 초안

### xv6
운영체제 과제를 통해 xv6의 시스템 콜, 스케줄링, 메모리 관련 코드를 수정하며 시스템 내부 동작을 직접 다뤄본 경험입니다.

### uftrace
오픈소스 컨트리뷰션 아카데미 uftrace 트랙에 참여하며 추적 도구의 역할과 오픈소스 협업 과정을 배웠습니다.

### Hackathon
랜덤 팀 구성의 해커톤에서 기능 우선순위를 조정해 제한 시간 안에 프로젝트를 완성한 경험입니다.

---

## Problem Solving 섹션 소개문
알고리즘은 제게 단순한 대회 성과가 아니라, 코드를 빠르게 읽고 문제를 분해하며 제약 조건 안에서 최적의 선택을 찾는 훈련이었습니다. 이러한 사고 방식은 운영체제 과제와 시스템 코드 분석을 이해하는 데에도 큰 도움이 되었습니다.

---

## 짧은 자기소개 문장
- C/C++ 중심의 시스템 소프트웨어 직무를 준비하고 있습니다.
- 운영체제, Linux, 메모리 구조에 관심이 많습니다.
- 알고리즘 경험을 바탕으로 문제를 구조적으로 분석하는 편입니다.
- 코드 분석과 최적화 관점의 개발을 선호합니다.
