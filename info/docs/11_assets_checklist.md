# 11. 포트폴리오 제작용 자료 체크리스트

Codex로 사이트를 완성하려면 아래 자료가 있으면 좋다.

## 필수
- GitHub 링크
- 이메일
- 대표 프로젝트별 저장소 링크
- 프로젝트 스크린샷 1~3장
- 수상/성적 증빙 이름 확인
- 이력서 PDF

## 있으면 좋은 것
- 문제 해결 프로필 링크
- 운영체제 과제 설명 메모
- uftrace 관련 활동 링크
- 자기소개 2~3줄
- 한 줄 포지셔닝 최종안

## 프로젝트별로 모아야 하는 것
- 프로젝트 이름
- 기간
- 역할
- 사용 기술
- 어려웠던 점
- 결과
- 대표 이미지
- 링크
- 내가 배운 점

## 공개 전 점검
- 링크 깨짐 없는지
- 과장된 표현 없는지
- 기술 스택이 실제와 맞는지
- 모바일에서 글이 잘 읽히는지
- 첫 화면 10초 안에 정체성이 드러나는지
