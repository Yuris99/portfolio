# 03. 기술 스택과 표현 기준

## 핵심 기술
### C / C++
- 가장 중요한 언어
- 알고리즘, 시스템 프로그래밍, 운영체제 과제와 연결
- 포트폴리오 메인 스택으로 배치

### Python
- 보조 언어
- 빠른 실험, 스크립팅, 데이터 처리, 간단한 AI/자동화에 사용
- 주력 언어처럼 과장하지 말 것

### Linux
- 기본 명령어, 구조 이해, 개발 환경 적응
- 커널/시스템 관심과 연결
- “리눅스 사용 가능”보다 “리눅스 내부 동작과 오픈소스에 관심”이 더 중요

### Git / GitHub
- 버전 관리 경험
- 오픈소스/개인 프로젝트 정리와 연결

### Docker
- 컨테이너 기반 실행 환경 경험
- 주력 역량은 아니므로 과하게 앞세우지 말 것

## 전공지식
- 운영체제
- 시스템 프로그래밍
- 프로세스/스케줄링
- 메모리 관리
- 동기화
- 예외/자원 관리 흐름 이해

## 문제 해결 역량
- Baekjoon Platinum 3
- Codeforces 민트, 최고 블루 언급 있음
- Codeforces Expert로도 표현된 적 있어 검증 필요
- 대회 성과와 함께 “코드 분석/최적화”로 연결할 것

## 표현 예시
좋은 표현:
- “C/C++ 기반 문제 해결과 시스템 프로그래밍에 강점이 있습니다.”
- “운영체제 과제와 xv6 수정을 통해 시스템 내부 동작을 직접 다뤄봤습니다.”
- “알고리즘 경험을 통해 빠르게 구조를 파악하고 효율적인 해법을 찾는 역량을 길렀습니다.”

피해야 할 표현:
- “풀스택 개발이 가능합니다.”
- “백엔드부터 프론트엔드까지 모두 능숙합니다.”
- “AI, 웹, 앱, 시스템을 모두 잘합니다.”
- “전문가 수준으로 능숙합니다.” (근거 없는 경우)

## 스킬 시각화 규칙
- 별점/퍼센트 대신 `주력`, `경험 있음`, `학습 중` 정도로 구분
- 가능하면 각 스킬 옆에 **근거 프로젝트/경험 링크**를 붙일 것
